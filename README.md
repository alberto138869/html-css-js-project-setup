# Projeto HTML, CSS e JavaScript

Esse é um projeto simples criado para aprender HTML, CSS e JavaScript.

## O que tem no projeto

- Página com layout responsivo usando HTML e CSS
- Contador interativo com botões de aumentar, diminuir e zerar
- Campo de texto que mostra a mensagem digitada dinamicamente
- Botão para mudar o tema de cor da página

## Como usar localmente

1. Abra a pasta do projeto no VS Code.
2. Abra o arquivo `index.html` no navegador.

Se quiser uma experiência mais próxima de um servidor, use a extensão Live Server do VS Code ou outro servidor local.

## Publicar no GitHub Pages

1. No GitHub, abra o repositório.
2. Clique em **Settings**.
3. Vá em **Pages** no menu lateral.
4. Em **Source**, selecione **main** e clique em **Save**.
5. Em alguns minutos, o site ficará disponível em `https://alberto138869.github.io/html-css-js-project-setup/`.
