# Relógio Digital em HTML Puro

Este repositório contém um relógio digital moderno, responsivo e totalmente construído com HTML, CSS e JavaScript puro.

## Funcionalidades

- Exibe a hora em tempo real
- Atualiza os segundos automaticamente
- Mostra a data completa em português
- Layout premium com visual dark neon
- 100% sem dependências externas

## Estrutura do projeto

- `index.html` — estrutura da página
- `style.css` — estilos visuais e responsividade
- `app.js` — lógica do relógio

## Como executar

1. Abra a pasta do projeto no VS Code.
2. Abra o arquivo `index.html` no navegador.
3. Ou execute um servidor local, por exemplo:

```bash
python -m http.server 8000
```

Em seguida, acesse `http://localhost:8000`.

## Publicação

O projeto pode ser publicado facilmente no GitHub Pages ou qualquer serviço de hospedagem estática.

A implementação foi pensada para ser simples, legível e eficiente, seguindo boas práticas de front-end vanilla sem frameworks ou bibliotecas.
